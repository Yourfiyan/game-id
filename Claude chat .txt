Purpose
Game ID answers questions about a library a person already owns — what is in it, where it came from, how trustworthy the metadata is, and what has never been touched. It is an analysis surface, not a play surface.

High-level goals
Make a large, messy, partially-enriched ownership dataset legible.

Ship a complete Figma design system before any application code is written.

Next build: Game Card / Grid on 10:20. Nine application screens, wireframes, and page templates remain untouched.

Design Philosophy
Design language: Microsoft Fluent 2. Neutral greys, restrained accent use, functional depth, 4px spacing grid, circular radii reserved for pills and avatars.

Core principles, in priority order:

The data decides the hierarchy. A field present on ~5% of rows never drives a sort, a chart axis, or a headline number. Sparse data appears as detail, never as structure.
Honest emptiness. Missing data is shown as missing — with a confidence indicator or an explicit empty state — never as a zero, a dash pretending to be a value, or a hidden row.
Never invent a token. A value gets a named, scoped variable in Figma first, then is consumed. No raw hex, no magic numbers in components.
Refine, do not reinvent. Once layout architecture is settled it is settled. Later passes adjust spacing, wording, and states — never navigation structure, card dimensions, or working components.
Contrast is measured, not eyeballed. Every foreground/background pair is computed against WCAG. Text targets 4.5:1, graphic boundaries target 3:1. Documented values must be measured in the same call that writes them, never recalled.
Density with air. Desktop-first means information density is a feature, but rows breathe (56px) and cards are generous (240×320 cover).
One component, many states. Every interactive component ships Rest / Hover / Focus / Disabled, and a state change must never change a control's footprint.
Explicit non-goals
No gradients. No glassmorphism. No blur-behind surfaces. No decorative illustration. No custom brand typeface. No animation beyond functional motion tokens. No mobile or tablet layouts in v1.

Architecture Decisions
Each of these is settled. Do not reinvent, re-litigate, or "improve" any of them without an explicit user instruction.

Focus ring convention — TWO rings, not one
This was never recorded and got rebuilt wrong once. Read this before building any focusable component. Verified live on Checkbox (106:53), Radio (106:86), Select (109:114), Text Input (107:140) and Filter Chip (115:74) — all five agree.

Two absolutely-positioned RECTANGLE siblings, no fills, inside the Focus variant.
Child order: inner first (beneath), outer last (on top).
Focus ring inner:  x/y = -1        size = body + 2   strokeWeight 1  ->  stroke/focus-inner
Focus ring outer:  x/y = -3        size = body + 6   strokeWeight 2  ->  stroke/focus-outer
both:              strokeAlign = 'INSIDE'
                   layoutPositioning = 'ABSOLUTE'   <- set BEFORE resize()
                   cornerRadius: inner = body + 1, outer = body + 3   (UNBOUND — plain numbers)
stroke/focus-outer is white in Dark / near-black in Light; stroke/focus-inner is the inverse. The pair reads on any surface — that is the whole point of the two-ring design.
Radii are deliberately left unbound. They are body-radius ± a fixed offset, not a semantic step on the radius ladder. Do not create a radius token to hold a ring radius — a radius/xxlarge was created for exactly that reason and had to be deleted.
The rings extend outside the variant's bounds, so the component set must have clipsContent = false or they will be invisible in the set. Variant frames themselves are already unclipped.
Set the paint's literal colour and bind the variable via setBoundVariableForPaint. Binding alone leaves a black literal that renders if the binding is ever dropped.
Specimen strip baseline alignment — for strips whose cells contain controls of differing heights:

strip.counterAxisAlignItems = 'MIN';
// wrap each instance in a fixed-height 'Holder' auto-layout frame (44px)
// -> all cells then measure identically (66px) and captions share one baseline

Quirk	Handling
figma.notify() throws	Never use it.
console.log() is invisible	return is the only output channel.
getPluginData / setPluginData unsupported	Use getSharedPluginData('dsb', key) / setSharedPluginData.
Colours are 0–1, not 0–255	Always normalise.
figma.currentPage = page throws	Use await figma.setCurrentPageAsync(page), at most once per script.
setBoundVariableForPaint returns a NEW paint	Capture and reassign — mutating in place silently does nothing.
combineAsVariants stacks variants at (0,0)	Set layoutMode, itemSpacing, padding, and primaryAxisSizingMode/counterAxisSizingMode = 'AUTO' on the set afterwards.
layoutSizing* vs *AxisSizingMode	Child: FIXED|HUG|FILL. Frame: FIXED|AUTO. Never cross them.
HUG/FILL rejected on unparented nodes	Append to the auto-layout parent first, then set sizing.
layoutSizingVertical = 'HUG' must be explicit	Otherwise a frame keeps its default height. This caused Buttons appearance rows to sit at 100px instead of 32px.
figma.createAutoLayout() ships a white fill	Every container needs fills = [].
findAll does not exist on TEXT nodes	Use a type-agnostic recursive walk.
INSTANCE_SWAP values are node ids	comp.id, not comp.key.
Font style is "Semi Bold"	"SemiBold" fails.
Existing text may have figma.mixed fonts	Iterate getRangeFontName(i, i+1) per character before mutating.
Alias-chain resolvers must be null-guarded	return (val && val.r !== undefined) ? val : null;
Alias resolvers must capture alpha	A resolver reading only {r,g,b} silently drops a, making alpha/white-06 look like opaque #ffffff at 16.48:1. Capture val.a; report opaque: (val.a === undefined || val.a === 1).
Cross-collection aliasing	Fall back to col.modes[0].modeId when valuesByMode[modeId] is undefined.
Mutation ordering matters	Clone a node before syncing the source's text, or the clone inherits the new string and the subsequent find(oldString) misses.
setVariableCodeSyntax string-replace is fragile	Building a sibling's syntax by string replacement produced colorconfidenceHigh. Always pass explicit target casing.
New icon glyphs default to constraints: MIN/MIN	Every existing icon uses SCALE/SCALE. A MIN glyph does not resize with its instance — it stayed 12.5px inside a 10px avatar. Always copy a peer's constraints: mg.constraints = pg.constraints, then re-resize() existing instances to force re-evaluation.
outlineStroke() inserts a sibling; the source survives	Append the outlined result to the component and remove() the source explicitly, or you ship two overlapping shapes.

A component set clips overflowing children by default	clipsContent defaults to true on a set created by combineAsVariants. Focus rings are the common casualty: they sit at negative offsets, so they render as nothing while every property check passes. Set set.clipsContent = false on any set whose variants have overflowing decoration. Variant frames themselves are already unclipped.
